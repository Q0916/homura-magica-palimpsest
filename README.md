# 마법소녀 호무라☆마기카 — PALIMPSEST (상편 공개 테스트판)

> ⚠ 극장판 『마법소녀 마도카☆마기카 〈발푸르기스의 회천〉』 결말을 포함한 시리즈 전체 스포일러가 있습니다.

회천 그다음, 마도카의 자리가 빈틈없이 메워진 세계. 호무라는 아무것도 기억하지 못한 채 준코 씨네 집의 딸처럼, 사야카의 가장 친한 친구로 정말 행복하게 살고 있습니다. 그 행복을 즐기면서 기억하고 있는 쪽만 아파지는, 비공식 텍스트 어드벤처 팬게임입니다.
